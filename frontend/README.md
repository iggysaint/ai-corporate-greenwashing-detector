# Frontend

The user interface for the AI Corporate Greenwashing Detector will be implemented in a future phase.

## Planned Capabilities
- Stock ticker input (e.g., `AAPL`, `MSFT`, `AMZN`, `TSLA`)
- Overall **ESG Integrity Score** presentation
- Transparent claim-by-claim breakdown with source evidence citations
- Standardized assessment categories:
  - Supported
  - Partially Supported
  - Inconsistent
  - Unsubstantiated
  - Insufficient Evidence
